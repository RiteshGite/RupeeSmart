# RupeeSmart 💸

RupeeSmart is a modern finance learning frontend project built using React and Tailwind CSS.

## Features

- Financial quizzes
- Money simulator
- Learning modules
- Responsive UI
- Progress tracking

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
